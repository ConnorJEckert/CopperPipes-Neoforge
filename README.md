# Simple Copper Pipes

A Vanilla+ item and fluid transport mod for Minecraft 1.21.1 using NeoForge.

Adds copper pipes, pumps, and valves for moving items, water, lava, and smoke between blocks.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.x

## Building

```bash
# Build the mod jar (output in build/libs/)
gradlew build

# Launch game client for testing
gradlew runClient

# Run data generators
gradlew runData
```
